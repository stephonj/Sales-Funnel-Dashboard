# Sales Funnel Analysis Dashboard (Excel)

# Summary

An interactive Excel dashboard that visualizes a five-stage sales funnel (Visitors, Leads, MQLs, SQLs, Conversions), stage-to-stage drop-off, and conversion rates across six months. Built with PivotTables, charts, and monthly slicers.

**Data note**: this project uses **sample data** created to model a realistic funnel. It is not data from a real company.

# Business Questions Answered
Where in the funnel do the most prospects drop off?

What is the overall visitor-to-customer conversion rate, and how does it change by month?

Which stage offers the biggest opportunity for improvement?

# Key Findings
The largest drop-off is Visitor to Lead (85%). Only 30% of SQLs become customers.

Overall conversion is about 1.2% (775 conversions from about 62,700 visitors across January to June).

Monthly conversion stayed between 1.16% (February) and 1.30% (June). June had the most conversions (150).

# Features
Funnel chart with drop-off analysis

Conversion rates from Visitor to Lead to MQL to SQL to Customer

Overall funnel conversion rate KPI

Monthly slicers for dynamic filtering

# Tools

**Microsoft Excel**: PivotTables, charts, formulas, slicers

# How to Use
